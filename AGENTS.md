# AGENTS.md

## Project Context

This is a Vite + React application with a Firebase backend and Vercel serverless functions.
Keep changes focused on the user's request and preserve existing project conventions.

## Key Files

- `src/`: frontend application source.
- `src/api/firebaseClient.js`: frontend Firebase SDK client.
- `api/`: Vercel serverless functions (for AI calls).
- `vite.config.js`: Vite config.
- `.env`: local environment variables (Firebase + Gemini API).

## Working Notes

- Use `npm run dev` for local frontend development.
- Run the relevant checks from `package.json` before finishing code changes.
